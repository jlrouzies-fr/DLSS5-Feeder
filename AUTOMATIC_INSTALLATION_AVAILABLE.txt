YOU PROBABLY DO NOT NEED TO INSTALL THIS BY HAND
================================================

There is a one-command installer. It does everything the README's manual
sections describe, and it is the recommended way to install.

    https://github.com/jlrouzies-fr/DLSS5-Feeder/blob/main/tools/Install-DLSS5Feeder.ps1


HOW TO USE IT
-------------
1. Download Install-DLSS5Feeder.ps1 from the link above.
2. Drop the .ps1 file next to your game's .exe.
3. Right-click in that folder and choose "Open in Terminal".
4. Paste this and press Enter:

       powershell.exe -ExecutionPolicy Bypass -File .\Install-DLSS5Feeder.ps1

5. Confirm the executable it proposes, and answer which neural consumer you
   want (Deep Fried Chicken, or Krish's RenoDX DLSS 5 add-on).

Or point it at the game from anywhere:

       powershell -ExecutionPolicy Bypass -File .\Install-DLSS5Feeder.ps1 "C:\path\to\game.exe"


WHAT IT DOES FOR YOU
--------------------
It reads the architecture and the render API out of the executable, then
downloads (once, into a cache) and installs:

  - ReShade 6.8+ with add-on support -- as a local DLL, or as the machine-wide
    Vulkan layer plus the ReShadeApps.ini entry, whichever your game needs
  - this feeder, from the latest release (addon32 + host64\ for a 32-bit game)
  - the ReShade framework headers
  - LumeniteFX (motion vectors)
  - your chosen neural consumer, and both NVIDIA runtimes
  - dgVoodoo2, for Direct3D 8/9 games
  - ReShade.ini and ReShadePreset.ini, with the motion-vector provider selected
    and both techniques enabled in the right order

Existing files are merged into and backed up, never replaced. It finishes with
a read-only verification pass and prints [ OK ] / [WARN] / [FAIL] for every
check, with the fix for each failure.


WORTH KNOWING
-------------
  - Windows Defender flags Deep Fried Chicken, because it hooks NVIDIA's NGX
    runtime with Detours and heuristics dislike that. The script tries the
    plain install first; only if Defender removes the file does it explain,
    ask, and add an exclusion for the game folder through a UAC prompt. Nothing
    is excluded without your yes.
  - Vulkan games need one UAC prompt, to register ReShade's layer and add the
    exe to ReShadeApps.ini. -NoElevate turns every such step into printed
    instructions instead.
  - -Consumer DFC or -Consumer RenoDX answers the consumer question in advance,
    for an unattended run.
  - Already have some of the pieces? Point -LocalFiles at a folder, or pass
    them one at a time: -DfcZip, -RenoDxAddon, -DlssNrDll, -DlssDll,
    -FeederZip, -ReShadeSetup, -LumeniteZip, -DgVoodooZip.
  - -Api D3D|Vulkan|OpenGL|D3D9|D3D8 overrides the detection. Some engines
    (Max Payne 3 among them) can run on either Direct3D 9 or 11; the script
    assumes 11 and says so.
  - The Discord download links inside the script expire. When one does, the
    script says so and tells you which parameter takes a fresh link or file.
